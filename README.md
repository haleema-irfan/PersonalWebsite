# Haleema’s Personal Portfolio Website  

A modern, responsive portfolio built with **Next.js** and **Tailwind CSS**. Designed to showcase projects, work experience, and skills with a focus on **performance, clean architecture, and maintainability**.  

---

## Live Demo  
[View Live Website](https://personal-website-omega-ivory-27.vercel.app/)  

---

## Motivation  
I built this portfolio to create a **professional, reliable, and maintainable platform** that not only highlights my work but also demonstrates my ability to engineer real-world, production-ready applications.  

- Static resumes and outdated READMEs weren’t engaging → I needed an **interactive showcase**.  
- I wanted to explore **Next.js navigation, reusable components, and DevOps practices** like CI/CD and custom domains.  
- The site had to **load fast, and be easy to update** as my projects evolve.  

---

## Tech Stack  
- **Frontend:** Next.js, Tailwind CSS  
- **Deployment:** Vercel  
- **Design:** Figma

---

## Key Features  
- **Responsive design** → seamless across desktop and mobile  
- **Reusable component library** → reduced code duplication  
- **Fast loading** with Next.js optimizations and lazy-loaded images  
- **SEO-friendly** with server-side rendering  
- **CI/CD pipeline** → automatic deploys on every commit
